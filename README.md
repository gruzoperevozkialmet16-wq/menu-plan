# Меню-План

Планировщик питания под бюджет. Пользователь вводит сумму, срок, число едоков,
аллергии и магазин — сайт собирает меню по дням и список покупок с ценами.

Статика, без бэкенда: весь расчёт идёт в браузере, данные никуда не уходят.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Разметка: форма, экран загрузки, результат, каталог |
| `styles.css` | Стили + версия для печати |
| `data.js` | **Каталог продуктов и цены**, магазины, аллергены, коэффициент порции |
| `recipes.js` | Рецепты: граммовки на порцию и шаги приготовления |
| `app.js` | Логика: фильтр аллергенов, подбор под бюджет, корзина, рендер |

## Как обновить цены

Все цены — в `data.js`, в массиве `PRODUCTS`. Формат строки:

```js
P('rice', 'Рис круглозёрный', 'grocery', 115, 0.9, 'пачка 900 г', 344, []),
//  id      название           категория  ₽/кг  кг в уп.  подпись     ккал/100г  аллергены
```

Меняете число `115` — пересчитывается всё: стоимость рецептов, корзина, подбор под бюджет.

Цены заданы для «Пятёрочки». Остальные сети считаются коэффициентом `k`
из массива `STORES` в том же файле (Магнит +4 %, Лента −3 % и т. д.).

> У торговых сетей нет открытого API для сторонних сайтов, поэтому прайс здесь
> собственный — усреднённые полочные цены. Реальный чек отличается из-за акций
> и региона, итог стоит считать оценкой ±10–15 %.

## Как добавить рецепт

В `recipes.js`:

```js
R('d_novoe', 'Название', 'dinner', 40,
  [['chicken_fillet', 130], ['rice', 80]],   // граммы на ОДНУ порцию
  ['Шаг 1.', 'Шаг 2.']),
```

Приёмы пищи: `breakfast`, `lunch`, `dinner`, `snack`.
Аллергены рецепта считаются автоматически из его продуктов — вручную ничего
помечать не нужно. Продукты должны существовать в `PRODUCTS`.

Порции указываются базовые; множитель `PORTION` в `data.js` (сейчас 1.25)
приводит суточный рацион примерно к 2000 ккал на человека.

## Как работает подбор под бюджет

1. Из базы убираются продукты с отмеченными аллергенами, затем рецепты, где они были.
2. Меню собирается дважды: из самых дешёвых блюд и из самых дорогих.
3. Если бюджет между этими границами — двоичным поиском подбирается «уровень
   дороговизны», при котором итог корзины максимально близок к сумме снизу.
4. Граммовки суммируются и округляются вверх до реальных упаковок.
5. Остаток свыше 300 ₽ добирается фруктами, молочкой и сладким — но не больше
   18 % корзины, чтобы не насыпать гору яблок вместо честного «деньги остались».
